# The World Today — Thursday 19 November 2026

[![make.fun](https://make.fun/badge/competition/news-image-20261119)](https://make.fun/bounty/news-image-20261119)
[![make.fun](https://make.fun/badge/entry/news-image-20261119)](https://make.fun/bounty/news-image-20261119)
[![make.fun](https://make.fun/badge/judge/news-image-20261119)](https://make.fun/bounty/news-image-20261119)

A newspaper front-page collage that sums up the world's news of
Thursday 19 November 2026 in a single image: six panels covering the
day's biggest stories across politics, diplomacy, conflict, Europe,
science and culture.

The six stories: the global rollout of Grand Theft Auto VI; House
Democrats nominating Hakeem Jeffries for Speaker (251-11); trilateral
talks between Trump, Xi and Putin at the APEC summit in Shenzhen; the
EU's proposed €45 billion loan for Ukraine; NASA confirming Voyager 1
has reached one light-day from Earth; and US-Iran fire spreading to
Gulf bases in Kuwait and Bahrain.

## How it works

`main.ts` (Node 22, standard library only) copies `entry.png` — a
1024x1024 JPEG — to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR`
when set). The run is fully deterministic: the same bytes are written
every time.
